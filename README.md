# Paragon PR7-M

A media player for Windows 10/11 that works the way **MPC-HC** (Media Player Classic - Home Cinema) works, in the
Paragon family look (PR7-Z, PR7-W, PR7-L, PR7-F, PR7-E, PR7-R, PR7-P). Python, PySide6 and Qt Multimedia (FFmpeg).

Status: mock-up for approval (`docs/mockup`, drawn by `tools/mockup.py`).
